## 8) ميزانية الحجم (من 12MB إلى هدف أصغر)

| المكوّن | الميزانية المستهدفة | التقنية |
|---|---|---|
| الغلاف الأولي (HTML/CSS/JS + ترخيص) | ≤ 1.5 MB | بدون أي صوت مضمّن |
| الخطوط (عربي + أمهرية WOFF2) | ~130 KB (موجودة فعلًا) | subsetting للأحرف المستخدمة فقط |
| الصور | ≤ 500 KB للفصل | SVG للأيقونات، WebP للصور |
| الصوت لكل فصل/لغة | ≤ 1–2 MB | Opus أو AAC بـ 20–24 kbps (المنتج الحالي يشحن 20kbps بـ11.7MB للكل — نجزّئه) |
| حزمة اللغة الكاملة (8 فصول + صوت) | ≤ 8–10 MB تُحمَّل تدريجيًا | Cache Storage + IndexedDB، تنزيل اختياري «حمّلي للعمل بدون إنترنت» |

**المبدأ:** أول فتح خلال ثوانٍ على شبكة 4G ضعيفة؛ الباقي يتدفق حسب الفصل. العاملة في منطقة ضعيفة التغطية تضغط «تنزيل الكل» مرة واحدة على Wi-Fi.
