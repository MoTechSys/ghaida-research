|---|---|---|
| **Must** | تحويل HTML الحالي إلى PWA مع تفعيل (رقم طلب + OTP، جهازان، token موقّع) | أسابيع 1–4 |
| **Must** | فصل الصوت إلى حزم فصول/لغة + تقليص الحجم للميزانية أعلاه | أسابيع 1–3 |
| **Must** | كتابة «خطة أول 7 أيام» + مراجعة السلامة والحقوق من مختص | أسابيع 2–5 |
| **Must** | Watermark باسم المشتري + صفحة إدارة الأجهزة | أسابيع 3–4 |
| **Must** | إطلاق Pilot (25 أسرة) بالتوازي | أسابيع 5–8 |

| **Should** | بوابة دفع رسمية + فوترة | أسابيع 9–12 |

### المخاطر وتخفيفها

| الخطر | التخفيف |
|---|---|
| نسخ المنتج وإعادة بيعه | watermark + تفعيل + جعل القيمة في التخصيص والتحديث (لا في الملف) + قبول أن الردع هو الهدف لا المنع |
| مساند للتدريب توسّع وتسحق السوق | التموضع: «قواعد بيتك المخصصة» — الحكومة لا تخصّص بيتًا بعينه |
| محتوى سلامة/حقوق خاطئ → مسؤولية قانونية | مراجعة مختص إلزامية + نص إخلاء مسؤولية + الالتزام الحرفي بنصوص HRSD ووزارة الصحة |
| جودة TTS ضعيفة بلغة جديدة | لا إطلاق لغة بلا اختبار استماع بشري (الأمهرية اجتازت 100% round-trip داخليًا) |
| العاملة تحذف بيانات المتصفح → تفقد الوصول | `storage.persist()` + إعادة تفعيل سهلة برقم الطلب |
| ربة المنزل لا تفتح المنتج بعد الشراء | رسائل تذكير واتساب يومية أول أسبوع مربوطة بـ«خطة أول 7 أيام» |
