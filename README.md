## المنهجية
كل تقرير يفصل صراحة بين:
- **[حقيقة موثّقة]** — لها مصدر مذكور.
- **[افتراض]** — منطق داخلي يحتاج تحققًا.
- **[توصية]** — قرار مقترح لا حقيقة.

والأماكن غير الموثّقة كُتب فيها حرفيًا `[DATA NOT AVAILABLE]`.

## الخلاصة التنفيذية
- المنتج الأقوى: **PWA خفيف** (غلاف ≤ 1.5MB) يفتح من رابط، يعمل دون إنترنت بعد التحميل.
- التفعيل: **رقم طلب + OTP**، ربط بجهازين كحد أقصى، license token موقّع RSA.
- الردع: **watermark اجتماعي** باسم المشتري ورقم الطلب — الهدف ردع إعادة البيع لا المنع الكامل.
- البداية: **لغة واحدة (أمهرية جاهزة)** + «خطة أول 7 أيام» كفصل جوهري.
- الاختبار: **Pilot مدفوع مع 20–30 أسرة** قبل التوسع في اللغات.
