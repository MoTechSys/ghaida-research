# غيداء — بحث السوق والمنتج (ghaida-research)

بحث سوقي ومنتجي مفتوح لمشروع **غيداء**: برنامج تأهيل العاملة المنزلية بلغتها وصوتها وقواعد البيت — للسوق السعودي والخليجي.

> مستودع المنتج نفسه: [MoTechSys/ghaida](https://github.com/MoTechSys/ghaida)

## منهجية البحث

- كل نتيجة موسومة: **[حقيقة موثقة]** (لها رابط مصدر) / **[استنتاج]** / **[افتراض للاختبار]** / **[توصية]**.
- لا ندّعي الاطلاع على آلاف الدراسات — نوثّق فقط ما تم الوصول إليه فعلًا.
- ما تعذّر توثيقه يُسجَّل صراحة في [حدود البيانات](document/13-data-limits.md).
- المستخدم ≠ الدافع: العاملة تستخدم، والأسرة/المكتب يدفعان.
